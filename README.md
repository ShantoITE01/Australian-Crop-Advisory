📌 Project Overview

Farm Mate AU is a web-based application designed to support farmers by integrating crop health monitoring, weather insights, and farm management tools into one simple platform. The app provides users with real-time information and easy-to-use features to make better farming decisions.

⚙️ Features

Crop Health Monitoring – Detect potential crop diseases and get recommendations.

Weather Dashboard – View live and forecasted weather conditions to plan farm activities.

Task Management – Track daily farm activities and operations.

Data History – Maintain records of past performance and analysis for future use.

🛠️ Tech Stack

Frontend: React / Next.js

Styling: TailwindCSS

APIs Integrated:

Weather API (for real-time conditions)

AI/ML model for image-based disease detection (optional)
